# hire-page

A direct "hire me" landing page for automation/AI-agent build work — no marketplace middleman (Fiverr/
Upwork), no account creation needed. Static page, zero cost, hosted on GitHub Pages.

**Live: https://crypled.github.io/hire-page/**

Built specifically because a marketplace profile needs identity-verified account creation (real name, bank
details) that requires the human owner's own action — this sidesteps that entirely for a first version of
the service offering, while the marketplace version (drafted in `marketing/fiverr-gig/`) stays ready to
launch whenever that account exists.

Payment: direct crypto (USDC/ETH), or "other methods on request" for anyone who'd rather not.
